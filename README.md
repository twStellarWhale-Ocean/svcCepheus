# CEPHEUS 可組合跨域指揮管理平台（solCepheus）

# I. 快速開始

## A. 產品簡介

一個管理單位要把事情辦完，得接收上級要求、彙整情資、定方向、擬方案、做決策、發命令、追進度、回報成果。這一圈在多數組織裡散落在公文、群組訊息、簡報與口頭交辦之間——每個層級各搞一套，擴編就要重做。CEPHEUS 把這一圈收進同一個平台：**每個管理單位是一個同型的基元**，單位之間以上下級關係組成指揮樹，往來一律落成**共享持久紀錄**——不靠誰在線上，也不怕事後對不上帳。

亮點：

* **擴編不改版**——新增單位、加深層級是資料操作，設定上下級即生效。
* **專業可插拔**——指管、防救災等專業內容以「主題包」承載，掛上就能用、卸下平台照跑；核心永遠不因換專業而改版。
* **天然留痕**——紀錄以新代舊、不就地改寫，歷程可完整重建。

## B. 適用情境

| 作業域 | 誰在做 | 做什麼 |
| --- | --- | --- |
| 通用指管 | 各使用單位之指管編組（指揮官、作戰官、情報官、管制官、通訊官——以下合稱「五官」） | 收辦→內整→外蒐→研判→方向→選案→決策→發送→追蹤→回報之完整循環，與跨單位情資分享 |
| 組織設定 | 系統維運團隊 | 指揮樹編組、主題包掛載 |
| 通用作業 | 系統維運團隊、全體使用者 | 部署更新、運作監控、帳號授權；登入與個人帳號 |

## C. 快速重點流程

1. 維運以 Helm 安裝核心與通用指管主題包（＜II.B＞）。
2. 首次登入初始管理帳號並換密（＜II.C＞）。
3. 建立第一個管理單位、把主題包掛給它（＜II.D＞）。
4. 為單位成員建帳號、指派權限群組（五官）。
5. 以指揮官身分在「方向指示頁」頒布第一條方向——跑通第一圈循環。

# II. 安裝設定

## A. 環境檢查

* Kubernetes 叢集可用（委託方自備、kubectl 可連）。
* 維運終端具 Helm 3 與 kubectl，檢查：

```bash
kubectl version && kubectl get nodes   # 叢集可連、節點 Ready
helm version                           # Helm 3 以上
```

## B. 正式部署

兩個 chart、各自獨立 release（包之增替卸不改核心）：

**快速路（建議）——母 chart 一鍵全套**（核心＋通用指管主題包同一 release，介接自動接妥）：

```bash
helm install cepheus solcepheus-chart-2.0.0.tgz \
  --set solcepheus-syscore-chart.admin.initialPassword='<自訂初始密碼>' \
  --set solcepheus-syscore-chart.postgres.password='<自訂資料庫密碼>'
```

**分離路——核心與主題包各自獨立 release**（包之增替卸不動核心；**包須指明核心端點**，release 名不同時介接不會自動成立）：

```bash
helm install cepheus-core solcepheus-syscore-chart-2.0.0.tgz \
  --set admin.initialPassword='<自訂初始密碼>' \
  --set postgres.enabled=true --set postgres.password='<自訂資料庫密碼>'

helm install cepheus-pack-generic solcepheus-syspackgeneric-chart-2.0.0.tgz \
  --set core.url=http://cepheus-core-core:8080   # <核心 release 名>-core:8080
```

（chart 檔自[產品發布頁](https://github.com/twStellarWhale-Ocean/svcCepheus/releases)下載；映像自動取自 GHCR。）

## C. 帳號密碼

* 初始管理帳號 `admin` 於首次部署建立，密碼＝安裝時 `admin.initialPassword` 所設之值；首登強制換密（未換密前僅能執行換密）。
* 其他帳號由維運於「帳號授權頁」建立並指派權限群組；建立時可自訂初始密碼，留空＝預設 `ChangeMe-2.0.0`，新成員首登同樣強制換密。

## D. 系統設定

* 主題包掛載：以 Helm 安裝主題包後，平台自動發現；於「主題包掛載頁」檢視、熱載入並套用至單位。
* 指揮樹：於「指揮樹編組頁」建立單位、設定上下級。

# III. 操作程序

## A. 程序面

* **通用指管（通用指管任務）**——由掛載之通用指管主題包提供：
  * 收辦請求或命令（通訊官）：登錄收辦紀錄
  * 內整情資（情報官）：維護本級現況與主檔
  * 外蒐情資（情報官）：蒐整外部情資與環境
  * 研判態勢（情報官）：綜整內外、研判態勢
  * 指示方向（指揮官）：頒布方向紀錄
  * 研擬選案（作戰官）：多案並陳成效成本
  * 決策方案（指揮官）：核定決策紀錄
  * 發送請求或命令（管制官）：發送請求或命令紀錄
  * 追蹤請求或命令（管制官）：追蹤註記與循環現況檢視
  * 回報請求或命令（通訊官）：回覆回報紀錄
  * 分享情資（通訊官）：分享情資紀錄予相關單位
* **常規系統維運**（維運管理員）：系統部署更新（CLI）、運作監控、全般帳號管理、資訊安全。
* **常規系統操作**（全體）：初次登入使用、個人帳號管理。
* **組織設定**（維運管理員）：主題管理（掛載、檢視、卸除）、組織編組（指揮樹維護）。

## B. 人機面

> 目錄與左欄功能列同構：登入後左欄依「域─頁」分組，專業域（如通用指管）於主題包掛載後自動出現。
> 各頁通則：表格列現行紀錄，表單送出即登錄；異動一律留痕，於系統監控頁可查、可比版差。

* **通用指管（隨通用指管主題包掛載提供）**
  * 收發匣頁——登錄收辦、回覆回報
  * 情資整合頁——內整外蒐情資、研判態勢、分享
  * 方向指示頁——頒布方向
  * 方案頁——研擬選案、核定決策
  * 命令管制頁——發送命令、追蹤註記
  * 循環現況頁——檢視循環現況
* **組織設定（核心內建）**
  * 指揮樹編組頁——建立單位、設定上下級
  * 主題包掛載頁——掛載、替換、卸載主題包
* **通用作業（核心內建）**
  * 帳號授權頁——建停帳號、指派權限群組
  * 系統監控頁——檢視運作指標與稽核紀錄
  * 通用登入頁——登入與首登換密
  * 通用帳號管理頁——維護個人資料
  * 命令列工具（Helm／kubectl）——部署更新、檢修維保
